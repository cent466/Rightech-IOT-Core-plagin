# Локальное испытание SVG и replay — 15.11.2026

Это ограниченный интеграционный прогон на локальном стенде с синтетическими
MQTT-клиентами. Физическое устройство, облачная RIC и другие версии не проверялись.
Подробные локальные артефакты не публикуются: они содержат идентификаторы стенда.

  Номер нового checkout не использовался как версия запущенного интерфейса.

TSDB и несколько других сервисов были недоступны; история не проверена.

## Импорт и данные

Оболочка, собранная `make_import_file.py`, принята штатным мастером **From URL**
по локальной ссылке. Интерфейс создал новый ID модели, отличный от ID оболочки.
Файловый диалог автоматизации не открылся; путь **From file** здесь не подтверждён.

На трёх отдельных объектах подтверждены нулевая температура, Boolean false,
строка `0017`, индекс массива `.0` и преобразование **235 → 23.5** при factor=0.1.
Отсутствующие измерения проверены на отдельном объекте без старых измерений.
Повторный прогон адаптированной модели ожидал новый timestamp каждого пакета.

ID `online` занят состоянием соединения: после отключения клиента он стал false,
при этом собственный `device_online`, извлечённый из payload, сохранил true.
Поэтому флаг payload в поставляемом примере имеет ID `device_online`.

При последовательной отправке `number[]` через JSON-контейнер:

| Вход | Текущий массив | Отдельный первый элемент |
|---|---|---|
| `[12.25,55.5,98.75]` | `[12.25,55.5,98.75]` | `12.25` |
| `[77.7]` | `[77.7]` | `77.7` |
| `[]` | `[]` | `77.7` |
| поле отсутствует | `[]` | `77.7` |

Массив этой сборки заменяется и очищается; прежний скаляр при отсутствии элемента
сохраняется. Это не эмуляция replay и не гарантия для других сборок/типов массивов.

## SVG

`display.svg` без `levels.svg` сохранился в модели, но интерфейс выбрал стандартные
иконки. С той же геометрией в `levels.svg` карточка и журнал показали свои SVG.
Копии в `display.svg` и `levels.svg` согласованы, `display.indicator=true`.

В светлой и тёмной темах подтверждены геометрия термометра и флага, отсутствие
обрезания самих иконок, наследование цветов `#2a9d64`, `#d89b16`, `#de4c55`
при значениях температуры 0, 23.5 и 35 соответственно. Размеры 12 иконок карточек
совпали в двух темах: примерно **16.19 × 16.19 CSS px** в данной среде.
Это измерение конкретного браузера, а не универсальный размер RIC.

На узком экране сами SVG остаются видимыми. Панель журнала шириной **600 CSS px**
не помещается в фактический viewport **355 CSS px** даже при свёрнутой навигации;
полную мобильную совместимость интерфейса этот тест не подтверждает.

## Команды

Команды с аргументами **0, 25, 100** доставлены MQTT-подписчику с точным JSON,
QoS 1 и retain=false. Подтверждена доставка синтетическому клиенту, не физическое
действие устройства. Из формы дополнительно получены команды с 0 и 25.

Вызов API с **101** при `opts.max=100` также доставил `{"target":101}`.
Локальный replay отклоняет его по своей политике качества. `opts.min/max` нельзя
считать подтверждённой серверной защитой команды. Поведение ввода 101 в форме
не используется для вывода о её ограничениях; проверялся фактический MQTT JSON.

## Границы вывода

Локальный replay сравнивает независимые пакеты с пустым состоянием и не моделирует
накопленное состояние, транспортный `online`, серверную проверку границ, UI,
обработчики, историю и физический эффект команды. Успешные локальные тесты
по-прежнему выдают `ric_verified: false`: это не сертификат произвольной модели.
